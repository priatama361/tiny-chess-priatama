A deterministic, standard-library-only chess engine packed into 4 KB of Python.

- Iterative deepening, quiescence search, transposition table, null-move pruning
- Piece-square tables, bishop pair, passed pawns and endgame king activity
- Built and verified with make.fun's `grade-local`: Elo 1451 on the practice trial

## Run

```sh
python3 -P -s main.py
```
